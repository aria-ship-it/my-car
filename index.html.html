🤔 思考：断电的灯泡为什么亮了？人体为什么能导电？ ▼点击查看核心知识点
人体内不仅含有大量水分，体液中还溶解了大量的电解质（如氯化钠等）。

这些电解质在体液中解离出了能自由移动的离子（如 Na+、Cl-），当双手握住电极时，离子定向移动形成了闭合电路，使得灯泡发光。这说明人体是一个良导体。

🚗 环节二：盐水动力小车与电离本质

关于“盐水动力小车”实验（不需要电池，仅靠“盐水”就能驱动小车），请同学们思考以下问题：

提问：① 氯化钠固体能不能导电？为什么？ ▼解析
不能导电。虽然 NaCl 固体中有离子，但被紧紧束缚在晶格节点上，不能自由移动。
提问：② 氯化钠溶液为什么能导电？ ▼开启微观动画观察
能导电。小车能跑的奥秘在于：NaCl 溶于水后，解离成了能自由移动的离子（Na+ 和 Cl-）。

✍️ 环节三：符号表征 - 电离方程式

1. 教师示范

NaCl = Na+ + Cl-

HCl = H+ + Cl-

NaOH = Na+ + OH-

2. 书写规则归纳

  1. 原子守恒与电荷守恒：方程式左右两边原子种类、数目必须相同，且正负电荷代数和为零。
  2. 原子团不拆：如 SO42-、OH- 作为一个整体书写。
  3. 符号准确：强电解质用“=”号，弱电解质用可逆符号。
✏️ 课堂演练：请书写硫酸和硝酸钡的电离方程式 ▼核对答案

1. 硫酸 (H2SO4) 的电离方程式：

H2SO4 = 2H+ + SO42-


2. 硝酸钡 (Ba(NO3)2) 的电离方程式：

Ba(NO3)2 = Ba2+ + 2NO3-

🔍 环节四：模型构建 - 重新定义酸碱盐

探究 1：观察 HCl、H2SO4，阳离子有何共同点？ ▼归纳【酸】
【酸的本质】：电解质电离时生成的阳离子全部是 H+ 的化合物。
探究 2：观察 NaOH、Ca(OH)2，阴离子有何共同点？ ▼归纳【碱】
【碱的本质】：电解质电离时生成的阴离子全部是 OH- 的化合物。
探究 3：观察 NaCl、Na2CO3，它们电离出了什么？ ▼归纳【盐】
【盐的本质】：电解质电离时生成金属阳离子（或 NH4+）和酸根阴离子的化合物。

⚖️ 环节五：分组实验 - 物质导电性与概念辨析

请同学们用微型导电仪测试桌上的试剂，我们汇总结果如下：

测试物质 灯泡现象 微观微粒状态
盐酸 / NaOH溶液发光 (导电)含有大量自由移动的离子
酒精 / 蔗糖溶液不发光 (不导电)以分子形式存在，不产生离子
NaCl 固体不发光 (不导电)离子被束缚在晶格中，不能移动
无水浓硫酸不发光 (不导电)纯净物，以分子形式存在，无水不电离

📌 核心考点：电解质与非电解质的严谨定义

【电解质】：在水溶液里 或者 熔融状态下能导电的 化合物。（如酸、碱、盐、水）

【非电解质】：在水溶液里 和 熔融状态下都不导电的 化合物。（如蔗糖、酒精、二氧化碳）

🚨 致命易错点：

  • 单质（如铜丝导电）和 混合物（如盐酸导电）因为不属于化合物，所以它们既不是电解质，也不是非电解质！
  • CO2 溶于水导电是因为生成了碳酸，而不是它本身电离，所以它是非电解质。

📋 环节六：课堂归纳小结

本节课我们完成了从现象到本质、从宏观到微观的化学思维跨越，请同学们记录核心知识图谱：

宏观辨识
➡
导电现象与分类：
能导电不一定是电解质（如金属、盐酸）。电解质必须是化合物。常见电解质包含酸、碱、盐和水。
微观探析
➡
电离的本质：
化合物在溶于水或熔融状态下，自发解离出自由移动离子的过程。强调：电离不需要通电！
符号表征
➡
电离方程式与酸碱盐：
严格遵守原子守恒与电荷守恒。通过电离生成的特定离子（H+ 或 OH-），严谨定义了酸和碱。

🏆 环节七：当堂达标与回归生活

一、当堂检测

1. 判断：电解质一定能导电，能导电的物质一定是电解质。（ ） ▼查看解析
两句话都错。
① 电解质在固体状态（如 NaCl 晶体）下不能导电，只有溶于水或熔融时才导电。
② 能导电的物质可能是金属单质（如铜）或混合物（如盐水），它们都不是化合物，不属于电解质。
2. 下列物质属于电解质的是（ ） ▼查看解析
A. 铜丝
B. CO2
C. NaCl
D. 稀盐酸
正确答案：C
解析：A 是单质（不属于），B 是非电解质（本身不能电离），D 是溶液属于混合物（不属于）。C 是化合物且溶于水能导电，是典型的电解质。
3. 下列物质不能电离出 Cl- 的是（ ） ▼查看解析
A. KCl
B. KClO3
C. HCl
D. MgCl2
正确答案：B
解析：氯酸钾中的原子团是氯酸根 (ClO3-)，电离方程式为 KClO3 = K+ + ClO3-，原子团不拆，无法单独拆解出游离的氯离子。

二、回归生活，学以致用

① 湿手为什么易触电？
生活用水中溶解了微量的杂质（盐类等电解质），它们在水中电离出了自由移动的离子，大大增加了水的导电能力，从而增加触电风险。

② 人体导电的奥秘是什么？
我们的血液、细胞液中含有大量的 Na+、Cl-、K+ 等离子。这些电解质解离出的离子，不仅让人体能导电，更是维持人体渗透压平衡和神经电信号传导不可或缺的微观使者！
